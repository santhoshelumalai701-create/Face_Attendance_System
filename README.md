# Face Attendance System

A desktop application that marks student attendance automatically using real-time face recognition.

## Features
- Register students by capturing their face
- Mark attendance live through a webcam
- Prevents duplicate attendance on the same day
- Saves a timestamped photo as proof for each entry
- View attendance records in the app

## Tech Stack
Python, OpenCV, DeepFace, Pandas, Tkinter

## How to Run
1. Run `setup.bat` to install the required libraries
2. Run `run_dashboard.bat` to start the application
3. Click **Register Student** to add a student
4. Click **Start Attendance** to begin marking attendance
